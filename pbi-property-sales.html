Power BI project · Data Analytics

NS Property & Parcel Sales Intelligence

An interactive Power BI suite for exploring Nova Scotia property sales across 355K+ records. The project brings together API ingestion, data preparation, semantic modeling, DAX measures, geospatial context, and stakeholder-friendly reporting.

Open in Power BI → More Power BI work
Live interactive report 2018–2026 · Nova Scotia property sales

Data ingestion & preparation

Connected to Nova Scotia DataZone through the Socrata API, then used filtering, profiling, normalization, address construction, and quality checks to prepare a usable analytical dataset.

Flexible semantic modeling

Designed a performance-aware analytical model using appropriate dimensional and relational techniques, with room to evolve as the reporting questions and source data change.

DAX & decision support

Built measures for median sale price, year-over-year change, sales counts, and interactive geographic exploration with tooltips and property-level context.
